## 朋友圈 / 公众号（短文）

**标题**：DSH 升级翻车、换电脑，终于不用重装一遍了

**正文**：
DeepSeek Harness 的所有数据都在 `~/.dsh` 里——会话、设置、技能、插件配置。一次升级失败、一次误删、一次换电脑，可能就全没了。

dsh-backup 0.14.0 做了几件事：

1. **一条命令备份**：`/backup`，带 sha256 校验、自动轮换；升级前自动拍快照，坏了随时回滚。
2. **恢复不赌运气**：先预览、先快照当前数据，失败自动回滚。
3. **换机不用重来**：单文件 ZIP 导出/导入，本地开发插件也能一起带走；WebDAV / S3 / Gist 多通道同步。
4. **凭据不上云**：Key / Token 默认脱敏，只留本机；想更稳可以给备份上口令加密。
5. **DSH 起不来也能救**：备份目录里自带零依赖救援控制台，双击「点我恢复」。

面板也重做了：三个 Tab、首启三步引导、主按钮只有一个。装完就知道下一步点哪。

真机验收：DSH 0.2.1-rc.2 上 e2e 70/70，smoke 587/565。MIT 开源。

安装：`dsh plugin --profile web add @xiaoyuyu6420/dsh-backup`

**心理学用法**：损失厌恶（升级/误删/换机三场景）→ 默认效应（一条命令、推荐自动备份）→ 互惠（免费开源、先给价值再求 Star）。

## 小红书笔记

**标题（≤20 字）**：DSH 数据备份，一条命令搞定

**正文（≤1000 字）**：

用 DeepSeek Harness 的姐妹应该都懂：所有会话、设置、技能、插件配置都在 `~/.dsh` 一个目录里。升级翻车、手滑删错、换电脑——没有备份就是真的没了🥲

最近在用的 dsh-backup 更新到 0.14.0，几个点很戳我：

✅ **一条命令备份**：输入 `/backup`，自动带校验、自动轮换；升级前还会自己拍快照，坏了回滚就行
✅ **恢复不赌**：先预览要恢复什么，当前数据先快照，失败自动回滚
✅ **换机不重来**：单文件 ZIP 导出/导入，本地开发插件也能带走；还能同步到 WebDAV / S3 / Gist
✅ **凭据不上云**：API Key / Token 默认脱敏只留本机，想更稳可以加口令加密
✅ **DSH 起不来也能救**：备份目录里自带一个零依赖救援控制台，双击「点我恢复」就能开
✅ **面板变好用了**：三个 Tab（备份/恢复/设置），首启三步引导，主按钮只有一个「立即备份」，第一次用也不会懵

安装（Web profile）：
`dsh plugin --profile web add @xiaoyuyu6420/dsh-backup`

桌面端在应用里「设置 → 插件 → 添加插件」输包名就行。

真机验收过 DSH 0.2.1-rc.2：e2e 70/70、smoke 587/565。MIT 开源，介意隐私的可以自己审计。
