# 0.14.5 — 大会话验证与备份状态修复

修复 #143：旧版 Doctor 将超出 V8 字符串能力的大会话误报损坏，导致新备份排除这些会话、暂停轮换，并让自动日志仍显示完成。

- 对输入、解压输出、单帧、单行和帧/行数设资源预算，避免完整解压内容拼成一个大字符串。
- 达到预算或无法读取/解码时标为「未验证」，不因此隔离或进入 Doctor 修复名单，不单独暂停轮换；入档范围继续遵循所选类型与排除设置。
- 已证实的坏帧、坏 header、JSON 和序号问题仍触发隔离及轮换保护。
- 自动备份区分完整、未验证、归档不完整和致命失败；警告落盘，重启后在命令和面板可见。
- 离线救援、迁移预检和恢复复检同步处理资源限制；恢复了未验证副本时不再声称全部健康。

## 验证与边界

全部使用临时合成数据；没有访问报告者的真实会话、备份或配置。Linux 本地验证：Node 24 主测试 596/596、Node 20 主测试 529/529、Node 22/24 新增回归各 29/29、Node 20 新增回归 23/23、settings 47/47、client 63/63、安全/恢复回归 27/27、tar 恢复单测 18/18，真实 DSH 0.2.2-rc.5 e2e 75/75。发布前由 PR CI 复验，并在 Windows 执行新增有界验证回归和已有大归档探针。

未验证不代表健康或损坏。大日志仍可备份和恢复原始字节，但超出资源预算的深度验证、迁移预检及 rewind 操作会明确停止。原报障文件没有复现，浏览器交互未人工验证。详细预算及覆盖范围见 [验证记录](../issue-143-validation.md)。
