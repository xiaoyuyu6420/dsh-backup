# dsh-backup 0.14.3 · 备份与恢复安全修复

本版把 [PR #139](https://github.com/xiaoyuyu6420/dsh-backup/pull/139) 已合并的修复发布到 npm，基于 main 的 `d03c840`。不改变归档格式或宿主版本声明。

## 修复内容

- 校验归档、插件元数据和写入路径，拒绝路径穿越、危险 profile 名及目标符号链接；仅导入所选节段，并遵守冲突保留决策。
- 分类型恢复或多插件导入失败时还原已覆盖内容，移除本次新建文件；修复本地插件 tarball、解包根目录及跨文件系统迁移。
- 敏感回滚副本写入本机 `vault/preserved/`，使用 0600 权限；tar 与 ZIP 排除深层凭据、自定义脱敏规则和旧版敏感留档。
- 原子锁事务防止并发操作同时执行；发现损坏会话或扫描失败时暂停旧备份轮换，避免删掉最后一份健康副本。
- 修复 Git 凭据助手的路径引用、导入预览数值校验，以及救援工具对超过 256 MiB 归档的校验。
- 备份目录位于 `DSH_HOME` 内时，全量、分类型、加密备份和 ZIP 导出均排除整个备份目录，避免把归档和 vault 再次打包。
- 真实宿主测试从同一套 npm/pnpm 安装解析 CLI 与会话解码器，并接入 PR 检查。

## 恢复前的目录要求

备份目录不能与 `DSH_HOME` 相同。若备份目录是其子目录，整包恢复前需把**整个备份目录（包括 vault）移到 `DSH_HOME` 外**，再更新插件备份路径或救援工具的 `--root`。程序会在移动原数据前拦截不安全布局；恢复预览和分类型恢复仍可使用。
